# 抗氧化成分筛选 Protocol v2.1 补充条款

版本：2.1；范围：Historical exploratory ranking policy；本补充条款不改变 v2.0 的候选范围、ORAC-FL 主指标、H/L 分臂、Stage 1/Stage 2、未来正式 Tier A、靶点证据或转化评价规则。

历史 ORAC-FL 证据分为四种用途。Tier A 为高置信正式可比证据，只用于未来 formal numerical ranking，其既有标准不降低。Tier B1 为 exploratory comparable：目标必须是身份明确的单体，ORAC-FL、H/L 分臂、AAPH、fluorescein、Trolox、温度及主要缓冲液/溶剂环境可确认，原始数值可追溯并能可靠换算为 mol TE/mol，且无已知严重光学或聚集伪影；允许缺失数值纯度、化合物专属完整线性区间、完整光学 QC 或少量读取参数。Tier B2 为 quantitative but low-comparability：虽有明确数值和基本可信的化合物身份，但方法元数据、归一化、变体兼容性或干扰控制不足，因此只作支持性定量证据。Tier C 为明确不兼容或不能转换；Tier X 为信息不足，尚不能判级。

Formal ORAC ranking 只纳入 Tier A。Exploratory Literature-Derived ORAC Comparison 可纳入 Tier A 与 Tier B1，但必须保留研究级数据点、协议差异和证据层级；B2、C、X 不进入主探索性数值图。任何探索性输出均不得称为 definitive ranking、validated Top20 或人体抗氧化效果。H-ORAC 与 L-ORAC 分臂展示，未经桥接验证不合并。

每个化合物若有至少两条独立 A/B1 记录，报告 n、median、min、max，并在 n≥4 时报告 IQR；只有一条记录时标记 single-study exploratory estimate。不得取最大值作为代表值，不用未分层 pooled mean，不把同一研究内技术重复当独立研究。无合格记录者编码为 not_measured_or_not_usable，而非 0。

本政策的解释边界为：图中的高值只能表述为“在已纳入的历史 ORAC-FL 文献中报告值较高”。它不表示人体效力、临床获益、生物利用度、疾病预防作用、细胞 redox regulation 或最终实验优先级。
