# Unified Literature-Evidence Screening

本模块回答 research maturity，而不是 antioxidant potency。`01_primary_ranking/` 是 Top50 research-evidence density；`02_metric_validation/` 比较 publication/citation 和 recent/historical；`03_shortlist_stability/`、`04_class_representation/` 与 `05_evidence_breadth/` 是 QC。导师优先查看 primary ranking、两张 metric validation 和 shortlist stability。数据来自 `data/literature_screening/`，R source 镜像位于 `R/03_unified_literature_screening/`。
