## Current ORAC model and external evidence review

Read the [model development record](../03_candidate_selection/01_activity_model/Model_Development.md), [external observation evidence queue](../03_candidate_selection/01_activity_model/results/External_Source_Validation_Queue.csv), [paper-level access and readiness](../03_candidate_selection/01_activity_model/results/External_Paper_Readiness.csv), [individual comparability decisions](../03_candidate_selection/01_activity_model/results/External_Comparability_Decisions.csv), and [scoped connectivity audit](../03_candidate_selection/01_activity_model/results/External_Connectivity_Readiness.csv). The [conditional mass-to-mole conversion audit](../03_candidate_selection/01_activity_model/results/Source_Normalization_Audit.csv) keeps original values and reference molecular weights separate from eligible model labels. The [two-observation retrospective pressure test](../03_candidate_selection/01_activity_model/results/Retrospective_Pressure_Test.csv) is separate from formal validation. [Methods](../06_manuscript/Methods.md) and [Results](../06_manuscript/Results.md) describe the reproducible analysis. These current CSVs include model-stage source checks that are not yet incorporated into the existing review workbook.

The [analysis-set decision table](../03_candidate_selection/01_activity_model/results/Analysis_Set_Decisions.csv) is the current entry point for primary/sensitivity/waiting dispositions and alternate references. Its [input manifest](../03_candidate_selection/01_activity_model/results/analysis_set_manifest.json) records hashes and unresolved primary-release requirements. A disposition is not human scientific approval.

Primary model scope: ORAC-FL at pH 7.4 and 37 C; final vehicle, AUC estimator and integration window are separate protocol strata. Scope matching does not release a model label.

The [protocol-lineage check](../03_candidate_selection/01_activity_model/results/Protocol_Lineage_Check.csv) distinguishes directly reported conditions, shared cited-SOP information and the executed protocol still requiring confirmation.

Use the [scope-filtered model-candidate coverage](../03_candidate_selection/01_activity_model/results/Model_Validation_Feasibility.csv) and [protocol-stratified extended feasibility](../03_candidate_selection/01_activity_model/results/Extended_Validation_Feasibility.csv) for current design checks; core-condition matching alone is not fitting approval.
