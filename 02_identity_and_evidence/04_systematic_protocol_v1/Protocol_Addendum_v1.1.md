# Protocol Addendum v1.1

Effective2026-11-17. Researcher stage decision GO WITH REVISIONS authorizes Stage2. This addendum governs prospective retrieval and screening. Protocolv1.0 and historical frozen assets retain their original content.

## Changes and rationale

REV01 adds method-only and compound-class routes without mandatory food terms to reduce missed pure-standard research. Topic/food and compound-specific routes remain complementary. Each platform requires an actual syntax test and known-original recall test. API acceptance, known-DOI lookup and broad-query recall are recorded separately. Institutional platform tests await access and exports.

REV02 makes insufficient independent original experiments,missing quantitative endpoints,missing essential protocol/control details and structural/common-comparator gaps the primary2016-2019 extension triggers. Paper counts remain coverage diagnostics. Case-specific extensions require logged evidence gaps. Potency and eligibility derive from experiments and scope.

REV03 separates AI predictions,researcher review and final adjudication. Automated exclusions retain recoverable records and undergo class/method-stratified recall-risk sampling,including all known-anchor misses. Before accepting automated exclusion policies,reviewer-labelled audit samples must estimate missed-eligible proportions and uncertainty. Risk thresholds and reviewer assignments remain researcher decisions. Included originals receive full-text appraisal and independent checking of identities,values,units,conditions and study dependence. Missing reviewer capacity retains PENDING.

REV04 retains first_public_date,formal_issue_date,index_date and date_evidence separately. Scope eligibility uses verified first public publication through2026-11-17. Date conflicts retain HOLD. Search execution date is recorded independently.

REV05 refines ORAC endpoints into raw fluorescence/time,AUC,blank-subtracted netAUC,netAUC-concentration slope,Trolox-normalized slope or calibrated molar capacity,lag time,decay rate and IC50-type protection. Probe FL,PE,PGR and other variants retain separate identities. Mass-normalized capacity,concentration-based TE and amount ratios retain explicit denominators. Each combination of probe,radical source,pH,temperature,vehicle and integration/calibration rule defines a comparability stratum.

Impact includes Stage2 query generation,Stage3 screening audits,Stage4 endpoint/normalization fields and Stage5 analysis sets. Existing snapshots and model inputs remain dated baselines. Changes represent researcher-directed protocol revisions and retain all subsequent scientific data-release gates.
