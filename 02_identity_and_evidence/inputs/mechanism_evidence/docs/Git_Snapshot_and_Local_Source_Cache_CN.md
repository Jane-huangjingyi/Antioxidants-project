# Git试点快照与本地来源缓存

本次Git提交保存待审试点，不是Release，也不批准Gate1/Gate2。用户在本轮提取结束后授权提交前整理、选择性commit与push。此前报告中的NOT_EXECUTED及开始/结束HEAD是当时的审计快照，按历史记录保留，不改写成事后状态。

证据CSV、字段字典、覆盖索引、研究登记、检索与筛选日志、QC、说明和脚本纳入版本控制。search_logs/raw/通过本目录.gitignore排除，原有全文、批量摘要响应和原始元数据仍在本地，未删除。本次未完成这些文件的公开再分发许可审核，因此不将可访问性等同于已允许随Git仓库发布。

search_logs/Local_Source_Cache_Manifest.csv保存每个本地来源文件的相对路径、大小、SHA256与可取得的来源URL。indexes/Evidence_Source_Provenance_Index.csv逐观察关联evidence_id、DOI、PMID、文章入口、局部定位及来源文件哈希，便于在不携带全文时追溯。

证据表中的source_local_path表示提取时实际使用的本地缓存路径，不承诺该文件存在于Git克隆中。全新克隆需要依来源URL、检索日志及检索脚本合法恢复来源后，才能重新做本地来源检查。URL明确区分实际保留地址与根据已知标识重建的恢复地址。重新查询的结果可能更新、受访问限制或不再可用；不能声称重新下载必定与历史哈希一致。完整版本复现还依赖原始缓存，本提交保留该边界，不虚称完全自包含。

qc/Final_Validation.json记录提取结束时本地环境的20项验证。提交前另以qc/Git_Snapshot_Preparation_Check.json验证既有639个跟踪文件及全部已核验CSV哈希不变。本轮整理未改变任何科学证据行、候选物身份、审核决定或既有源表。独立科学审查、未筛文献、来源矛盾和通路标准化仍待处理。
