# Unified Literature Screening 数据

`master/` 是 157 候选的一行一候选汇总；`provenance/` 是一行一候选×论文；`shortlist/` 分开保存 research-density Top50 与 H-ORAC retrieval-eligible subset；`qc/` 保存检索日志、OpenAlex audit、cutoff sensitivity 和 Top50 targeted QC。正式指标名称为 `metadata_deduplicated_original_publication_N`；旧字段 `antioxidant_independent_publication_N` 仅为 backward compatibility，不能称为真正 independent-study count。
