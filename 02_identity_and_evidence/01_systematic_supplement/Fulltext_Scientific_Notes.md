# First recovered-source scientific checks

## DOI 10.3164/jcbn.11-21

Checked the Experimental headings, Table 1 caption, assay columns and reference footnotes in recovered Europe PMC XML. The original experimental arm uses ORAC-EPR and dimethyl-beta-cyclodextrin-solubilized materials. Table 1 also lists literature ORAC-FL values with source-specific reference markers. The FL column therefore requires mapping to the cited original studies before deduplication or inclusion. It cannot automatically contribute an independent FL observation from this paper. Original EPR measurements require their own method/estimand scope and material conditions. Numeric FL entries have not been substituted for unrecovered original sources.

This first check records method and provenance classification. It does not release a new model label or approve a source HOLD. Remaining recovered articles are pending corresponding original-method, figure/table and independence review. Source XML location and hash are in Method_Fulltext_Queue.csv, and table IDs are in Fulltext_Table_Locators.csv.

Table notes say 1 micromolar test compound, while the ORAC output unit is mmol TE/L. The extraction preserves the table value, conflicting narrative and concentration/unit ambiguity. DOI 10.3390/molecules29102370 supplies an original ascorbic-acid row of 5982 micromol TE/g at pH 7.4 and 37 C with a 50-minute integration. Exact ascorbate form, final solvent, numerical error and the printed 153 micromolar AAPH working concentration remain unresolved. The catechin standard is explicitly racemic hydrate. Its value cannot be silently assigned to an exact catechin stereoisomer.

The reported mass-normalized capacities can be converted conditionally with the parent reference MW. The checked ORAC methods specify 37 C but leave pH, final vehicle and independent unit unresolved.

Previously reported crude extracts remain separate from the original isolated-compound experiment.
