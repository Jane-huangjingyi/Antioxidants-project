# Stage25B Primary H-ORAC Top20 导师摘要

本项目从 157 种水相候选开始，经统一研究基础筛选得到 Top50，其中 47 种进入 H-ORAC 检索；在 canonical H-ORAC Evidence Rubric v2.0 下，最终 28 种具有 A/B1 可比定量证据。研究者选择 Option C，并冻结 eligibility-defined Primary H-ORAC Top20（A+B1），用于下一阶段多维 translational characterization。

Frozen Top20 为：Rosmarinic acid, Epicatechin, Catechin, Caffeic acid, Apigenin, Naringenin, Kaempferol, Daidzein, Hesperetin, Protocatechuic acid, Genistein, Quercetin, Fisetin, Rutin, Sinapic acid, p-Coumaric acid, Hesperidin, Luteolin, Naringin, Ferulic acid。rank20 Ferulic acid 为 4.032 mol TE/mol，rank21 Morin 为 3.8745，差 0.1575。若在 sensitivity analysis 中纳入 B2，则 Cyanidin 3-O-glucoside、Baicalein、Cyanidin 进入，Luteolin、Naringin、Ferulic acid 离开。因此该集合是 eligibility-defined primary set，而不是 absolute antioxidant ranking；它也不是人体疗效、营养价值或转化优先级排名。1,641 条记录仍待裁决，故本次为项目级冻结而非穷尽性系统综述关闭。

下一步只允许基于该 frozen set 开展 food source/exposure、human evidence、PK/bioavailability、mechanism/redox biology、direct target、safety/prooxidant、tractability 与 evidence stability 的多维画像；不得以简单加权或全局综合分数替代多维判断。
