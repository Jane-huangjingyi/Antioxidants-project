# Stage 00 — Scientific question definition

## 1. Stage purpose

解决：界定正常膳食、结构明确的原型小分子，并区分 chemical capacity、人体相关性、机制和 target evidence。。

## 2. Why this stage was necessary

项目需要先区分 chemical antioxidant capacity、biological redox effect 与 translational priority，避免把不同问题混为一个排名。

## 3. Input

最初 Phase 0–1 protocol 与决策日志；仅使用项目现存数据、冻结决策与可追溯来源。

## 4. Method

审阅相应 protocol、结构化数据、脚本、图形和 change log；按当时冻结规则执行身份核对、assay 判定、证据分层、聚合或框架设计。未完成的动作不写成结果。

## 5. Decision rules

证据质量高于数量；化学能力不等于人体功效；H/L 不无条件混排；缺失数据不记为零；glycoside/aglycone、stereoisomer、salt/hydrate 不合并；direct target 与 pathway effect 分层。具体规则以本阶段列出的源文件为准。
