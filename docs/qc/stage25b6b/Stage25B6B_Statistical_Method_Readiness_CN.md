# 统计方法可行性

现有 A+B1 中位数是效力排序统计量，不能转译为 95%CI、Top20 入选概率或统计显著性。68 条记录只有 3 条明确 SD，23 条 ± 类型未明；Caffeic Acid 和 Gallic Acid 各有两项已核实独立原始实验，但尚缺少充分的逐研究误差定义与可比性数据。因此候选物 CI 与 rank probability 均不可估。多记录候选物可报告中位数、IQR、范围作为描述性记录间离散度；只有已核实独立来源的子集可谨慎称研究间比较。若后续明确均值、SD、实验 N、重复类型及方法可比性，可预注册研究层级随机效应模型或层级贝叶斯模型，并用敏感性分析检查单位换算和协议差异；本轮不改变 canonical 中位数。
