# SOP 02 Literature Search

版本：1.0；所有判断须遵循 MASTER v1.0，冲突进入 gap audit。

## Purpose

形成可审计、可复查的检索记录

## Scope

candidate universe中的每个候选

## Required input

候选名称、同义词和检索日志模板

## Required tools

PubMed、Google Scholar、Crossref、期刊网站

## Step-by-step procedure

逐一运行四个标准检索式；记录日期和命中；从review追到original；检查supplement

## Decision rules

Review只做线索；无法获取原文不得当B1

## QC checklist

检索式原样保存；排除原因成组统计；第二人抽查高重要性缺失项

## Common mistakes

只记录找到的文献而不记录没找到；用综述表格代替原文

## Required output

完整search log和候选文献清单

## Stop condition

每个候选有可证明的检索记录

## Example

EGCG检索必须同时查AAPH、fluorescein并排除β-PE。
