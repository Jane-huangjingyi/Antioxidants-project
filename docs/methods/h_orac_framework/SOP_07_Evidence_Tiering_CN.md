# SOP 07 Evidence Tiering

版本：1.0；所有判断须遵循 MASTER v1.0，冲突进入 gap audit。

## Purpose

按可比性而非期刊声望分层

## Scope

完成提取和换算的record

## Required input

v2.1、rubric、checklist

## Required tools

人工审阅表

## Step-by-step procedure

两人独立判A/B1/B2/C/X；写rationale；解决分歧

## Decision rules

A正式；A+B1探索排名；B2支持；C不兼容；X信息不足

## QC checklist

不得用分数投票替代关键门槛；保留初判与终判

## Common mistakes

为凑数据降B1；把高影响因子当A

## Required output

tier和理由

## Stop condition

两位复核者一致或第三人裁决

## Example

C3G有数值但光学QC不足，判B2。
