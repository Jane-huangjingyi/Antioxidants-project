# SOP 05 Record Level Data Extraction

版本：1.0；所有判断须遵循 MASTER v1.0，冲突进入 gap audit。

## Purpose

把原文证据变成可审计记录

## Scope

通过身份与assay初筛的原文

## Required input

ORAC record模板

## Required tools

PDF、Excel或CSV编辑器

## Step-by-step procedure

一项独立实验一行；录入书目信息、exact location、原值、条件、身份、提取者

## Decision rules

技术重复不拆行；不同arm分行

## QC checklist

双人逐字符复核原值和单位；必填字段不得空白

## Common mistakes

一化合物一行；只保留换算值

## Required output

record-level CSV

## Stop condition

原值、来源位置和关键方法齐全

## Example

同论文的quercetin与catechin分别成行。
