# SOP 03 ORAC Assay Eligibility

版本：1.0；所有判断须遵循 MASTER v1.0，冲突进入 gap audit。

## Purpose

判定记录是否属于当前H-ORAC-FL构念

## Scope

所有候选原始全文

## Required input

方法、结果、supplement及checklist

## Required tools

PDF阅读器、eligibility rubric

## Step-by-step procedure

确认pure compound、AAPH、fluorescein、Trolox、H-arm；定位原值；记录排除项

## Decision rules

β-PE、HORAC、L-ORAC、extract/food、review-only和不可读图不能B1

## QC checklist

每项判断有页码；探针和radical generator不可凭标题推断

## Common mistakes

看到ORAC就纳入；把fluorescein-HORAC误当ORAC-FL

## Required output

tier候选和exclusion log

## Stop condition

能够判A/B1/B2/C或X

## Example

Ou 2002 fluorescein HORAC仍是C。
