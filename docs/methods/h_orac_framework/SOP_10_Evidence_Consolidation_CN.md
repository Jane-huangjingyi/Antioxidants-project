# SOP 10 Evidence Consolidation

版本：1.0；所有判断须遵循 MASTER v1.0，冲突进入 gap audit。

## Purpose

验证高位单研究候选和关键缺失项

## Scope

provisional ranking、coverage和missing list

## Required input

targeted search log、exclusion/change templates

## Required tools

同SOP02工具

## Step-by-step procedure

按触发条件定向检索；不降低tier；复算；更新before/after

## Decision rules

只添加真正独立B1；所有变化写change log

## QC checklist

重点审查outlier、类别缺失和figure-only记录

## Common mistakes

无差别扩大候选池；静默替换旧值

## Required output

consolidation records和稳定性表

## Stop condition

target list和未解决风险可明确陈述

## Example

EGCG通过探针追溯排除错误来源后补入B1。
