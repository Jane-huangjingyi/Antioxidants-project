# 05. Analysis and editable figures

The current manuscript figures are generated by `R/render_manuscript_figures.R` from the actual discovery/selection tables. Edit the explicit font, color palette, point size, line/grid settings, dimensions, labels and layers in that script. Outputs use scientific task, version and format directories under `06_manuscript/figures`.

`python run_pipeline.py` renders three current figures. `python run_pipeline.py --legacy-figures` additionally runs the maintained historical R recipes relocated to `legacy_modules`. Those supplementary figures read the preserved source baseline and never revise current candidate decisions or frozen values. Existing modules are adapted at their active source locations instead of introducing another opaque rendering wrapper.

Both PNG and SVG are exported. `svglite` keeps text and vector geometry; color bars use vector rectangles. Illustrator edits should be saved separately under `manual_edits` and linked to their generated parent, because rerunning R overwrites generated exports. The workflow validates SVG text/vector structure; it does not claim to have interactively tested every drawing in Illustrator.

Future actual absorbance data are analyzed with Step 04's explicit code and an approved calibration/QC model. Synthetic computational checks, if used in QC, are never manuscript experiment data.
