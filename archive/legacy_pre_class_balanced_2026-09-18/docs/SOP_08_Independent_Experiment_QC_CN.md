# SOP 08 Independent Experiment QC

版本：1.0；所有判断须遵循 MASTER v1.0，冲突进入 gap audit。

## Purpose

防止同一数据被重复计权

## Scope

全部A/B1及引用链

## Required input

作者、DOI、数值、方法、批次信息

## Required tools

文献管理器、Excel

## Step-by-step procedure

建立experiment ID；比较数据来源；标记复用、review和重复出版

## Decision rules

同数据集只计一次；不同化合物可各有record但各自ID

## QC checklist

同一compound+ID唯一；疑似重复由第二人复核

## Common mistakes

把review引用算新研究；把技术重复算独立

## Required output

去重记录及ID

## Stop condition

所有eligible记录完成独立性判断

## Example

同论文同一ORAC表中的同化合物只有一个experiment ID。
