# Top20 evidence consolidation：导师汇报

本轮 consolidation 的目的，是验证 provisional Top20 是否只是由单篇论文和检索起点驱动，并补查 EGCG、kaempferol、myricetin、花色苷、黄烷酮和木脂素。所有新数值必须来自可追溯的原始 AAPH–fluorescein–Trolox ORAC 研究；β-phycoerythrin、HORAC、L-ORAC、综述二手值和无法精确读取的图形均不进入 B1。

本轮新增 18 条独立 B1。更新后前三名为 epicatechin、catechin 和 quercetin。Kaempferol、naringenin、EGCG、myricetin 新进入 Top20；gallic acid、tyrosol、carvacrol、thymol退出。Epicatechin、catechin、quercetin 的证据升为 High；rutin、genistein、p-coumaric acid 升为 Moderate。Quercitrin、trans-resveratrol 和 gentisic acid 仍是单研究估计。

EGCG 现在有两条合格 B1，位列第 12。此前缺失的主要原因是可检索结果混有 β-phycoerythrin、HORAC、L-ORAC 和 figure-only 数据，而不是 EGCG 的 ORAC-FL 必然较低。Cyanidin-3-O-glucoside 虽有精确值，但缺少充分的 inner-filter、光谱重叠、quenching、自发荧光和 pH 转化控制，故保持 B2。Secoisolariciresinol 未找到可用原始 ORAC-FL，且未用 enterodiol/enterolactone替代膳食母体。花色苷和木脂素仍被 ORAC-FL 文献系统性低覆盖。

更新 Top20 中 11 项达到 Ready for target mapping，9 项为 Conditionally ready。因而可以冻结一个分层的 `Target_Mapping_Shortlist_v0.1`，建议先对 11 项 Ready 候选开展下一阶段 pilot；9 项单研究候选保留在 shortlist 中但显式标注不确定性。当前所有合格记录仍为 B1，Tier A 为 0，因此本结果仍是历史文献 provisional ranking，不是统一实验标准值。
