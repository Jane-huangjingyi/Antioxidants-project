# Food-derived antioxidant candidate selection

We identify defined dietary compounds with high expected aqueous antioxidant capacity and reproducible original evidence. We use assay-specific measurements to prioritize candidates for prospective absorbance-based validation. [Latest results](Latest_Results.md) opens the current figures, tables and working manuscript.

Read [Latest results](Latest_Results.md) for the outputs and [Methods](06_manuscript/01_methods_working.md) for the screening, model and decision rule. Continue on `codex/systematic-antioxidant-evidence-20261117`. The first-round manuscript and ranking are anchored to `e4c300c`. This handoff describes the working state as of 2026-11-26.

## Continue the work

1. **Resume original-source extraction.** Use the [full-text queue and screening guide](02_identity_and_evidence/06_machine_screening/README.md). Prioritize high-ranked compounds supported by one report and studies with shared compounds that connect protocol blocks. Open Methods, original tables and supplements. Record DOI, locator, exact compound form, unit and denominator, pH, temperature, assay and AUC protocol, uncertainty type, repeat definition and primary-experiment overlap. Log the reason for every hold or exclusion. Where source access remains pending, preserve the row and its status in the evidence ledger.
2. **Prepare the next ranking round.** Start from the [intake template](02_identity_and_evidence/inputs/templates/evidence_update_intake.csv) and the [model update instructions](03_candidate_selection/README.md#reviewed-evidence-updates). First resolve the high-impact unit, calibration, uncertainty and source-independence issues in the [targeted follow-up](03_candidate_selection/12_evidence_expansion/README.md). After eligibility review, run the update in a separate output directory. Report whole-DOI holdout performance against the baseline on matched observations, DOI-deletion bounds, protocol and weighting sensitivity, and the candidate count for both rounds. Review movements before updating the compound inclusion table, round comparison and manuscript.
3. **Adjudicate the mechanism map in parallel.** Begin with the P0 rows for quercetin, chlorogenic acid and hesperetin in the [review checkpoint](02_identity_and_evidence/result/table/04_candidate_in_vivo_mechanism_evidence.md#researcher-review-checkpoint). Return the observation ID, verdict and original figure or page. Keep these observations separate from the molar-capacity model.
4. **Advance the assay after design approval.** Confirm the actual Flex setup and use the [pilot design](04_05_experimental_validation/02_pilot_design/README.md) to establish blank and calibration behavior, probe interference and repeatability before setting final parameters. The resulting raw trace data and protocol QC will support a later experimental Results section.
5. **Update the release together.** Regenerate the affected tables and Figure 1 PNG/SVG pairs, update Methods and Results with the corresponding denominators, and run [QC](07_quality_control/README.md). Mark each report with its cohort and checkpoint. Keep local licensed exports, source caches and virtual environments out of Git.

For the first session, steps 1 and 3 can begin by reading the existing tables. For a fresh clone, check the [environment guide](00_project/Environment.md) and the [snapshot prerequisites](02_identity_and_evidence/06_machine_screening/README.md) before attempting a full replay. Git contains the tracked outputs and provenance references. Rebuilding the literature-screening corpus also requires the local exports and XML batches.

## Reproduce

Use the [environment guide](00_project/Environment.md). Run `python run_pipeline.py --literature` with the local search exports to reproduce discovery, title and abstract screening, conditional models and the full-text work queue. Run `Rscript 06_manuscript/code/02_render_manuscript_panels.R` for working PNG/SVG pairs. Use the [frozen evidence reference](02_identity_and_evidence/inputs/provenance/results1_v1.0/README.md) to reproduce the original Results 1 release.

The active literature results remain conditional. Full-text eligibility and independent experiment checks are ongoing. The new aqueous absorbance assay is at the design stage.
