# Protocol v1.0 to v2.0 Change Log (English)

| v1.0 content | v2.0 treatment | Rationale |
|---|---|---|
| Main list restricted to naturally occurring, structurally defined dietary parent small molecules | Retained and frozen | Ensures chemical identity, dietary relevance, and reproducible extraction |
| Polyphenol-first generation without a class quota | Retained | Avoids a predetermined class conclusion while allowing cross-class competition |
| Metabolites separated from parents | Retained; metabolites become mandatory Stage 2 annotations | Prevents chemical-entity tier mixing while representing actual human exposure |
| Evidence quality outranks publication count | Retained | Prevents publication-popularity bias |
| Direct target is not an early hard gate | Retained | Avoids excluding important food compounds with sparse target literature |
| T1–T5 target system | Retained unchanged | Prevents pathway regulation and predictions from being presented as direct binding |
| Safety/dose window as a separate dimension | Retained as a Stage 2 risk modifier | Chemical capacity cannot replace dose feasibility or safety |
| Synergy/antagonism and food matrix | Retained as a context layer | Combination effects do not define intrinsic single-compound capacity |
| PK separated from efficacy | Retained and strengthened | Exposure is not evidence of clinical benefit |
| The 25/25/20/15/15 composite could determine the final list | Renamed the legacy Translational Priority Score; no longer generates the chemical Top20 | The supervisor requested one unified and interpretable chemical-ranking construct |
| Multiple antioxidant evidence dimensions jointly influenced an “antioxidant ranking” | Split into Stage 1 ORAC-FL and Stage 2 translational priority | Removes construct mixing between chemical capacity and biological relevance |
| Cell-free assays were low-level supportive evidence | ORAC-FL becomes a conditional Stage 1 primary metric but remains nonhuman evidence | The task now first compares chemical capacity; no human inference is permitted |
| DPPH/ABTS/FRAP contributed antioxidant evidence | Demoted to secondary and prohibited from forming a default total | Their constructs are limited by artificial radicals, medium, sterics, or reducing-power specificity |
| CUPRAC was supplementary | Elevated to the preferred orthogonal secondary assay | Adds an ET/reducing-power dimension complementary to peroxyl chain breaking |
| TRAP was supplementary | Retained as peroxyl-trapping confirmation | It is related to ORAC but not methodologically or computationally equivalent |
| Literature ORAC comparability was not explicitly gated | Added A/B/C/X eligibility framework | Prevents pooling across protocols, arms, and information-deficient reports |
| ORAC aggregation statistics were unspecified | Added median, range/IQR, stratification, and rank-band rules | Prevents maximum-value selection and false precision |
| H/L ORAC could appear to share a scale | Arms are separated unless bridging validation exists | Solvent, solubilization, and calibration differ between arms |
| ORAC missingness could affect eligibility | Missing is coded explicitly, never zero or exclusion; a measurement-priority list is created | Missing data are not biological low values |
| A single Top20 label | Split into Chemical Antioxidant Capacity Top20 and Translational Priority Top20 | Aligns each conclusion with one inference question |
| Cross-class comparison was broad | Added class-specific QC and arm strategies for polyphenols, tocopherols, carotenoids, and organosulfur compounds | Prevents systematic bias from lipophilicity, optical artifacts, or mechanism mismatch |
| No explicit ban on default multi-assay composites | Averaging and default z-scores are prohibited; profiles/concordance are used | Different assays measure different constructs and cannot create a valid common scale by convenience |

v2.0 does not discard human, exposure, mechanistic, or target evidence. It assigns them to the correct Stage 2 inference layer. This restructuring produces no candidate ranks.
