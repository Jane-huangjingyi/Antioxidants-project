# 00. Research scope

**Question.** Which discrete compounds with traceable dietary occurrence should be prioritized for aqueous antioxidant capacity verification?

**Inputs and rules.** Read the [protocol](Protocol.md), [decision register](Decision_Register.md), and [search protocol addendum](../02_identity_and_evidence/04_systematic_protocol_v1/Protocol_Addendum_v1.1.md). The scope excludes mixtures as quantitative pure-compound labels and separates chemical capacity from biological efficacy.

**Implementation and handoff.** The [environment](Environment.md) and [file policy](File_Management.md) define how to run the scripts. Use the protocol as input to [01 discovery](../01_candidate_discovery/README.md) and [02 evidence review](../02_identity_and_evidence/README.md). Changes to the scientific scope belong in the decision register.
