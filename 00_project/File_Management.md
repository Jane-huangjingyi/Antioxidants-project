# File and workflow policy

Organize by scientific task and execution step before version and format. Numbered folders describe the research sequence; they do not encode evidence strength. Each step owns its scientific code, inputs and results. Shared I/O does not hide selection logic. Manuscript projections link to, rather than replace, their source-stage tables.

Current documentation, code comments, table schemas and new narrative outputs are English. Original-language source records, article quotations and approved historical records stay immutable in the baseline. Preserve old IDs and meaningful filenames. A move changes a path, not scientific validity, approval or source date.

Generated figures use task/version/png or svg directories with a shared basename. Manual edits use a separate date-labelled folder. Do not put unrelated scientific tasks together under a folder named final or latest. All producers and current consumers must change together when paths change.

Use one preserved source baseline and one active research chain. A copied record with a distinct freeze, audit, governance or reconstruction role is not automatically redundant. Source snapshots, important process files and contradictory evidence are retained. Delete a temporary redundant mirror only after an exact retained counterpart and consumers have been verified and the action logged.

The design follows the task-first, immutable-source and explicit-version principles observed in the IBD project's file policy and integration README. Those files were read only for organization; no cohort data, scientific thresholds or analysis results were copied into this project.
